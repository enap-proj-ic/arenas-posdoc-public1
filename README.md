# ARENAS — public project website

Public, responsive website for the ARENAS postdoctoral research programme.

## Visual reference

The interface is based on the final V6 flash-talk presentation used at the São Paulo School of Advanced Science on Regulatory Governance (FGV Direito SP, 6 August 2026):

- ivory backgrounds and dark editorial sections;
- charcoal/navy structure with amber accents;
- large typographic hierarchy and uppercase overlines;
- the project roadmap `Done / Under way / Next`;
- the sociomaterial prototyping double cycle;
- a public QR call-to-action.

## Files

- `index.html` — page structure and accessible content.
- `styles.css` — responsive visual system for desktop, tablet and mobile.
- `app.js` — searchable product catalogue and modal details.
- `assets/qr-more-info.svg` — QR code for the public website.
- `.github/workflows/pages.yml` — GitHub Pages deployment.
