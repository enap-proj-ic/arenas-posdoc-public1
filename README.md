# ARENAS — Programa de Pesquisa Pós-Doutoral

Repositório público da página institucional do programa **ARENAS — Arquitetura Reguladora das Experiências e Negociações da Ação nos Serviços Públicos**.

O programa investiga prédios públicos como arenas sociomateriais de implementação de políticas públicas.

- Pesquisador: Igor Caires Machado
- Instituição: Escola Nacional de Administração Pública — ENAP
- Página pública: https://enap-proj-ic.github.io/arenas-posdoc-public1/

Este repositório contém apenas materiais públicos de apresentação e divulgação. Dados brutos, credenciais, manuscritos em avaliação e materiais sensíveis permanecem fora desta publicação.
